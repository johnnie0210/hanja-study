# 한자 공부 앱 (기말)

엑셀(`기말_한자.xlsx`)에 정리한 한자를 **카드 뒤집기**와 **퀴즈**로 공부하는 앱입니다.
스마트폰에서 홈 화면에 설치(PWA)해서 오프라인으로도 사용할 수 있습니다.

## 주요 기능

- **📇 카드 학습** — 앞면에 한자, 뒷면에 음·뜻·구성 한자
  - 덱 선택: `성어`(사자성어·단어) / `개별 한자` / `전체`
  - 섞기, 좌우 스와이프, 진행률 표시
- **❓ 퀴즈** — 3가지 유형 × 4가지 범위
  - 유형: 한자→음, 한자→뜻, 음→한자
  - 범위: 사자성어 / 성어 전체 / 개별 한자 / 전체
  - 문제 수(10·20·전체), 무작위 / 자주 틀린 것 순서
  - 채점 결과와 오답 목록, "틀린 것만 복습"
- **📖 목록** — 전체 항목 검색·필터
- **학습 기록** — 외운 카드·푼 문제·정답률을 기기에 저장

## 파일 구성

```
hanja-app/
├─ index.html              앱 화면
├─ styles.css              스타일
├─ app.js                  앱 로직
├─ data.js                 ← 엑셀에서 자동 생성 (직접 수정 금지)
├─ manifest.webmanifest    PWA 설정
├─ sw.js                   서비스 워커 (오프라인)
├─ icons/                  앱 아이콘
└─ build/
   ├─ parse-xlsx.mjs       엑셀 → data.js 변환
   └─ package.json
```

## 엑셀 수정 후 다시 반영하기

엑셀(`기말_한자.xlsx`)을 고친 뒤 아래를 실행하면 `data.js`가 다시 만들어집니다.

```powershell
cd build
npm install          # 최초 1회
node parse-xlsx.mjs "..\..\기말_한자.xlsx"
```

## 엑셀 형식 (Sheet1)

| A열 | B열 | C열 |
|---|---|---|
| 한자 | 뜻 | 음 |

- **빈 줄**을 기준으로 문제 묶음을 구분합니다.
- 각 묶음은 `개별 한자들` + `합성어(사자성어/단어) 1개` 순서로 적습니다.
- 예시)

  | 吾 | 나 | 오 |
  |---|---|---|
  | 鼻 | 코 | 비 |
  | 三 | 석 | 삼 |
  | 尺 | 자 | 척 |
  | 吾鼻三尺 | 내 코가 석 자… | 오비삼척 |
  | *(빈 줄)* | | |

## 배포 (GitHub Pages)

1. GitHub에 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages** 에서
   - Source: `Deploy from a branch`
   - Branch: `main` / 폴더: `/ (root)`
3. 잠시 후 `https://<아이디>.github.io/<저장소>/` 접속

### 스마트폰에 설치

- **Android(Chrome)**: 주소 접속 → 우측 상단 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **iPhone(Safari)**: 주소 접속 → 공유 버튼 → **홈 화면에 추가**

설치하면 일반 앱처럼 아이콘이 생기고, 오프라인에서도 열립니다.

> **참고**: 서비스 워커가 **network-first** 방식이라, 엑셀을 고쳐 `data.js`를 다시 올리면
> 설치된 앱도 다음 접속 때 최신 내용을 자동으로 받아옵니다. (오프라인이면 캐시된 내용을 사용)
> 그래도 예전 내용이 계속 보이면 `sw.js` 안의 `CACHE` 이름을 `hanja-study-v3` 처럼 올려 주세요.
