# 한자 공부 앱 (기말)

엑셀(`기말_한자.xlsx`)에 정리한 한자를 **카드 뒤집기**와 **퀴즈**로 공부하는 앱입니다.
스마트폰에서 홈 화면에 설치(PWA)해서 오프라인으로도 사용할 수 있습니다.

## 주요 기능

- **📇 카드 학습** — 앞면에 한자, 뒷면에 음·뜻·구성 한자
  - 덱 선택: `성어`(사자성어·단어) / `개별 한자` / `전체`
  - 섞기, 좌우 스와이프, 진행률 표시
- **❓ 퀴즈** — 3가지 유형 × 4가지 범위
  - 유형: 한자→음, 한자→뜻, 음→한자
  - 범위: 사자성어 / 성어 전체 / 개별 한자 / 전체
  - 문제 수(10·20·전체), 무작위 / 자주 틀린 것 순서
  - 채점 결과와 오답 목록, "틀린 것만 복습"
- **📖 목록** — 전체 항목 검색·필터
- **학습 기록** — 외운 카드·푼 문제·정답률을 기기에 저장

## 파일 구성

```
hanja-app/
├─ index.html              앱 화면
├─ styles.css              스타일
├─ app.js                  앱 로직
├─ data.js                 ← 엑셀에서 자동 생성 (직접 수정 금지)
├─ 기말_한자.xlsx          공부할 원본 엑셀
├─ manifest.webmanifest    PWA 설정
├─ sw.js                   서비스 워커 (오프라인)
├─ icons/                  앱 아이콘
├─ .github/workflows/
│  └─ update-data.yml      엑셀 업로드 시 data.js 자동 생성
└─ build/
   ├─ parse-xlsx.mjs       엑셀 → data.js 변환
   └─ package.json
```

## 엑셀만 올리면 자동 반영 (GitHub)

GitHub 저장소에 `기말_한자.xlsx` 파일을 올리거나 교체하면, GitHub Actions가
자동으로 `data.js`를 다시 만들어 커밋합니다.

1. GitHub 저장소에서 `기말_한자.xlsx`를 업로드/교체합니다.
   - **Add file → Upload files** 로 올리거나, 기존 파일을 열어 **Replace** 합니다.
   - 파일 이름은 반드시 `기말_한자.xlsx` 그대로 유지해 주세요. (이름이 다르면 자동 반영되지 않습니다.)
2. **Commit changes** 를 누릅니다. (가능하면 `main` 브랜치에 직접 커밋)
3. 저장소의 **Actions** 탭에서 `Update hanja data` 워크플로가 실행됩니다.
4. 완료되면 `data.js`가 자동으로 갱신되고, 잠시 후 사이트에 반영됩니다.
   - 서비스 워커가 **network-first**라서 앱을 다시 열면 최신 내용을 받아옵니다.

> 워크플로가 실패하면 **Actions** 탭에서 로그를 확인해 주세요.
> 저장소 **Settings → Actions → General → Workflow permissions** 가
> **Read and write permissions** 인지도 확인하면 좋습니다.

## PC에서 직접 반영하기

엑셀(`기말_한자.xlsx`)을 고친 뒤 아래를 실행하면 `data.js`가 다시 만들어집니다.

```powershell
cd build
npm install          # 최초 1회
node parse-xlsx.mjs
```

- 저장소 안의 `../기말_한자.xlsx`를 자동으로 찾습니다.
- 다른 경로의 엑셀을 쓰려면 `node parse-xlsx.mjs "..\..\기말_한자.xlsx"` 처럼 경로를 넘기면 됩니다.

## 엑셀 형식 (Sheet1)

데이터는 **B~D열**에 `한자 / 뜻 / 음` 순서로 들어 있습니다. (A열과 1행은 비어 있어도 됩니다.)

| B열 | C열 | D열 |
|---|---|---|
| 한자 | 뜻 | 음 |

- **빈 줄**을 기준으로 문제 묶음을 구분합니다.
- 각 묶음은 `개별 한자들` + `합성어(사자성어/단어)` 순서로 적습니다.
- 한 묶음에 합성어가 여러 개 있어도 각각 별도 항목으로 만들어집니다.
- 예시)

  | 吾 | 나 | 오 |
  |---|---|---|
  | 鼻 | 코 | 비 |
  | 三 | 석 | 삼 |
  | 尺 | 자 | 척 |
  | 吾鼻三尺 | 내 코가 석 자… | 오비삼척 |
  | *(빈 줄)* | | |

## 배포 (GitHub Pages)

1. GitHub에 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages** 에서
   - Source: `Deploy from a branch`
   - Branch: `main` / 폴더: `/ (root)`
3. 잠시 후 `https://<아이디>.github.io/<저장소>/` 접속

### 스마트폰에 설치

- **Android(Chrome)**: 주소 접속 → 우측 상단 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **iPhone(Safari)**: 주소 접속 → 공유 버튼 → **홈 화면에 추가**

설치하면 일반 앱처럼 아이콘이 생기고, 오프라인에서도 열립니다.

> **참고**: 서비스 워커가 **network-first** 방식이라, 엑셀을 고쳐 `data.js`를 다시 올리면
> 설치된 앱도 다음 접속 때 최신 내용을 자동으로 받아옵니다. (오프라인이면 캐시된 내용을 사용)
> 그래도 예전 내용이 계속 보이면 `sw.js` 안의 `CACHE` 이름을 `hanja-study-v3` 처럼 올려 주세요.
